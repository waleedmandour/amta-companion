AMTA Companion

Local lexicography engine — the Option C companion for the AMTA Lexicography Assistant add-on.

v0.1.0 — Bootstrap (M0)

This first release proves the cross-platform shell and the release pipeline:

  • ✅ Desktop shell builds on Windows (.msi/.exe), macOS (.dmg, universal) and Linux (.AppImage/.deb/.rpm)
  • ✅ Tag-driven release pipeline (GitHub Actions) + draft-release QA gate
  • 🚧 M1 — LM Studio bridge + OpenAI-compatible local API (tunnel + bearer token)
  • 🚧 M2 — Manuscript reader + grounded definitions with source URLs
  • 🚧 M3 — Drive-mailbox mode (no tunnel needed)
  • 🚧 M4 — OS-level code signing (Apple notarization, Windows Trusted Signing)

Using this release

v0.1 is a pipeline-validation release: install it, confirm it opens on your platform, and watch for the auto-updater groundwork landing in v0.2 (M1). Unsigned builds may show a Gatekeeper/SmartScreen notice — see the README for the one-click bypass.
